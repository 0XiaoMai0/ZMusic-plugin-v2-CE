# ZMusic CE 2.14.0-CE.6 更新说明

更新整理日期：2026-10-04。基于官方 ZMusic **2.14.0**，本次发布汇总 CE.2 至 CE.6 的改动，并替换仓库原来的 2.12.0 社区版源码。

## 本次主要更新

1. **更新官方基线与兼容实现。** 在官方 2.14.0 源码上重新整理社区功能，移除逐 Minecraft 版本的 NMS 子模块，采用公开 Bukkit 消息接口，保留 1.8 ActionBar 降级与原有模组播放协议。
2. **补齐多平台搜索、播放和歌词。** 支持网易云、QQ、酷狗、酷我；搜索结果保留歌名、歌手和歌曲编号，点击结果按 ID 点歌。支持 LRC 多时间标签、毫秒、offset 与平台提供的翻译，空地址和无效音频不显示播放成功。
3. **重做哔哩哔哩播放。** 从视频独立音轨取得 AAC，用纯 Java 在内存中适配为 MP3，再通过原有协议交给游戏模组。没有 FFmpeg、转码二进制、音频落盘或网页播放器。设置有界缓存与两首并发限制，同曲目复用结果。
4. **中文提示与账号兼容。** 播放失败、平台限制、网络异常、登录状态及诊断摘要改为中文。酷狗兼容多种账号字段；遇到 `30020` 或版权限制时按实际响应说明，不承诺刷新 Cookie 一定恢复。
5. **完整指令 Tab 补全。** `/zm`、`/zmusic`、`/music` 共用参数树，按权限补全平台、登录操作、歌单、曲目编号和缓存结果。密码、验证码、Cookie 不提供候选。
6. **QQ 与酷我原生登录流程。** QQ 接入 QQ/微信扫码与手机短信登录；酷我接入图形验证码后的账号密码、短信登录。自动创建缺少的账号文件，成功后原子保存，失败保留旧凭据。二维码/图形验证码仅短期保存在服务器内存中。
7. **修复 QQ 和酷我播放鉴权。** QQ 请求补齐音乐账号 key、uin、登录类型及鉴权散列；酷我官网请求补齐当前访客校验头。QQ 付费曲目在没有有效凭据时明确说明权限，不再返回已验证失败的备用地址；酷我明显过短的片段或提示音会被拒绝。
8. **关闭官版更新检查。** 删除启动、管理员进服与指令中的官版接口，旧配置的 `check-update` 自动保存为 `false`。`/zm update` 仅显示社区版更新说明，避免安装官版覆盖社区功能。

## 升级方法

正常停止服务器，备份 `plugins/ZMusic`，移走旧 ZMusic Jar，放入本次 `ZMusic-CE-2.14.0.jar` 后启动。账号文件不会因首次初始化被覆盖，不要同时保留多个 ZMusic Jar。客户端安装对应 Minecraft 版本的官方 ZMusic Mod。

使用 B 站或登录二维码的公网服，将 `audio-stream.public-url` 设置为玩家/管理员能访问的地址；远程客户端不能使用服务器的 `127.0.0.1`。服务器运行不需要 Node.js、Python 或 FFmpeg。

## 登录示例

```text
/zm login qq qr
/zm login qq qr wechat
/zm login qq sendcode +86 <手机号>
/zm login qq verify +86 <手机号> <短信验证码>
/zm login kuwo captcha
/zm login kuwo password <账号> <密码> <图形验证码>
/zm login kuwo sendcode <手机号> <图形验证码>
/zm login kuwo verify <手机号> <短信验证码>
```

登录需要管理员权限；控制台不加 `/`。网易云的多种账号登录方式仍需要兼容 NeteaseCloudMusicApi 服务；默认 `direct` 模式提供公开音乐接口。QQ 密码与酷我扫码未接入。登录不会自动获得会员、购买或地区版权权限。

- 最新构建：70 项测试通过，1 项可选网络测试跳过；Purpur 26.2 正常加载 CE.6，旧更新开关自动关闭。
- CE.4/CE.5：实际服务器注册的三个指令别名分别通过 51/54 项补全检查。
- CE.5 真实接口：QQ/微信二维码和等待扫码状态正常；酷我取得图形验证码并拒绝错误验证码；QQ 可建立匿名短信会话并拒绝无效手机号。完整账号授权、本人短信接收、密码及会员歌曲尚未完成真人验收，成功路径以模拟响应测试覆盖。
- QQ“宝宝巴士”、酷我公开样例取得有效 MP3 与歌词；QQ《晴天》周杰伦原唱在未登录时未取得 URL，酷我验证的是 KTV 伴奏版。平台接口及歌曲权限仍可能变化。

- 纯 Java 与 Java 8 字节码设计兼容 Windows/macOS/Linux，但当前实际环境为 Windows；中间版本、macOS/Linux、代理服与 Folia 未完成运行实测。旧客户端是否有对应模组需单独确认。

Jar 保持约 1.62 MiB。发布附件提供插件 Jar、对应完整源码及 SHA-256 校验文件；保留原作者信息和 GPL-3.0，源码不包含测试世界、账号 Cookie 或构建缓存。
